# 实施状态与发布门槛

本次交付为无兼容层的模块化重构，版本为 **1.0.2-alpha.1 预览版**。不将 89 条需求全部标成已完成，也不将预览版等同于稳定版。逐项关联见 `requirements-status.csv`，原始需求和优先级不因发布而改变。

## 已实现并纳入自动检查

中立平台/SDK/第二模块、统一 UI、DSH 公开槽位、单源 schema/Remote、服务端身份和作用域、Herdr 管理、显式归属与绑定、终端控制租约/接管/帧连续性/背压/生命周期、原子存储/元数据审计、独立包与构件来源。

历史本地 quality、真实 Herdr 集成及离线浏览器结果只用于相应源码工作树，不能替代最终验收。合并必须以当前 PR 提交在 GitHub 的 quality、integration、browser 三项通过为依据；GitHub 预发布还要求合并后的 main 提交重新通过全部三项检查。最终 tarball 的真实 DSH 安装、认证、终端输入、双窗口控制和卸载不得跳过。

## 预览版边界与稳定版剩余门槛

| 条目 | 尚需证据/动作 | 归属 |
|---|---|---|
| IND-01 | GitHub fork 网络实际 detach 或迁入新独立仓库；保留历史。 | 仓库管理员 |
| IND-02 | 最终品牌/仓库命名及 npm scope 发布权限确认；本次只发布 GitHub 预览版，不发布 npm。 | 维护者 |
| TER-08 | 物理中文输入法、特殊键、移动软键盘、剪贴板权限与跨浏览器实测。 | 人工验收 |
| UI-07/08/10、QA-05 | 自动键盘/axe/断点检查之外，真实读屏器、触屏与整套页面人工检查。 | 人工验收 |
| QA-07 | 按固定设备完成首屏/输入延迟与长时稳态压力预算，不以单元队列上限代替性能结论。 | 性能验收 |
| QA-03/06、SEC-03 | 当前最终构件在声明的 DSH/Herdr/OS 上的真实安装、认证与浏览器检查。 | 当前 PR/main CI 必过，不可延后 |

Mac、Windows、其他 DSH/Herdr 版本均未宣称支持。运行前检查资源预算和数据目录权限。控制台提供真实 shell 权限，只在可信设备和私有认证环境使用。

## 合并与发行

维护者在 2026-10-22 明确授权完成验证后合并并发布 GitHub Release。本次落实为 **1.0.2-alpha.1 prerelease**，而非稳定版或 npm 发布；上述人工、管理员及后续阶段边界必须同时写入发布说明。

CI 仅在本仓库 main push 且 quality/integration/browser 全部成功后，使用同一次运行已验证的构件发布这一明确版本。先校验 SHA256SUMS、包名、版本和 build SHA，再创建草稿、核对附件并公开预发布；不覆盖已有标签、附件或发行说明。PR 分支无发布权限步骤。最终代码保留许可证和来源；安装/卸载不删除外部资源。稳定版发行另需完成剩余人工与管理员门槛并独立批准。
