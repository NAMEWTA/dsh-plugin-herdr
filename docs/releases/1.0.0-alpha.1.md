# Workbench 1.0.0-alpha.1

**Breaking-change preview / 破坏性变更预览版。** This is an independently maintained modular-workbench implementation, not a stable release or a claim that every item in the design roadmap is complete. No npm publication is performed.

## What changed

- Separate platform contracts, core, module SDK, scoped UI, workbench shell and DSH adapter. Herdr is the first business module; a development-only notes module validates extension boundaries.
- Unified React interface for overview, attention, workspaces, agents, terminals, environment and appearance; Chinese/English, light/dark, comfortable/compact layouts.
- Public DSH extension slots replace private DOM/Fiber patches. Schema-generated Remote methods use the host's authenticated gateway and React singleton.
- Explicit workspace ownership, scoped operations, atomic persistence and bounded metadata audit. Terminal observation is read-only by default; controller acquisition/takeover is explicit, with leases, frame sequencing, input acknowledgement, backpressure and safe disconnect handling.
- Reproducible workspace dependency lock, architecture/type checks, regression tests, browser accessibility checks and final-tarball DSH installation tests.

## Install / 安装

The tested target is **Linux x86_64, Node 24.22.0, pnpm 10.28.2, DSH 0.2.1-alpha.2 and Herdr 0.9.3 / protocol 22**. Herdr and DSH run on the same host. Other platforms and versions are not claimed as verified.

Download the `.tgz`, `SHA256SUMS`, `build.json` and `sbom.cdx.json` from this release into one directory, then verify `sha256sum --check SHA256SUMS`. The package is **`@namewta/dsh-workbench`**, not the old Herdr plugin. Remove the old plugin before installing this package into the same Web profile:

```sh
dsh plugin --profile web remove @namewta/dsh-plugin-herdr
dsh plugin --profile web add /absolute/path/namewta-dsh-workbench-1.0.0-alpha.1.tgz
# Restart DSH Web after replacing the plugin.
dsh web
```

No old exports, APIs, configuration or routes are supported. Existing profiles, credentials, workspaces and external agents are not automatically deleted or migrated. Back up configuration before trying the preview. See `docs/installation.md` for environment configuration and rollback boundaries.

## Validation and provenance

Publication is gated on the same main commit passing build, strict types, dependency boundaries, generated contracts, unit/component/package regressions, real Herdr resource/terminal integration, real HTTP browser accessibility checks and installation of this exact tarball in published DSH. The attached `build.json` records the commit; `SHA256SUMS` covers the package and metadata; the SBOM and bundled license notices accompany the build. Checksums are integrity records, not a code-signing claim.

## Known limits / 已知边界

Physical Chinese IME/mobile keyboards, touch, screen readers and long-duration performance acceptance remain manual work. GitHub fork-network detachment and final repository branding remain administrative work; package independence does not mean the fork relationship has been removed. Multihost, structured chat, PWA/notifications, production standalone hosting and untrusted third-party plugins are later phases, not implemented release promises. The development host is not a production server and the SDK is not a sandbox.

**This console exposes real shell capabilities as the operating-system user. Use trusted devices and a private, authenticated environment. Do not expose it as an unauthenticated public service.**
