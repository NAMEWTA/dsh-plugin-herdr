# Workbench 1.0.3-alpha.1

**补丁预览版。** 从已发布的 `1.0.2-alpha.1` 起，数字 patch 加 1，后缀仍是 `-alpha.1`。只发 GitHub prerelease，不发 npm，不覆盖 `v1.0.2-alpha.1` 或更早的 Release。

宿主基线是 **DSH 0.2.1-rc.2** 与 **Herdr 0.9.3 / protocol 22**。已经发布的 `v1.0.2-alpha.1` 附件仍对应旧的 DSH `0.2.1-alpha.2`，不要把它当成这一版。

## 这次改了什么

### Ovis 风格看板

Herdr 总览改成工作室布局：页眉、进行中的计数、工作区卡片和待处理事项在同一页。左侧是模块轨和可收起的功能导航，管理页与 Herdr 分开。面板默认只读；控制和接管仍要单独确认。

### 会话右侧栏

DSH 右侧栏注册 Herdr 页签，显示当前会话绑定工作区里的终端和 Agent。空态有图标、说明和「为此路径创建并绑定工作区」，不需要模型，也不需要调用工具。绑定后的树分工作区、标签页和终端；行里有 Agent 标识、状态图标和状态文字。数字标签页显示为「标签页 1」。宽度收窄时文字可以换行。样式写在插件自己的根上，并注入到 Shadow Root。

### 会话台账与归属树

界面里为当前会话创建并绑定工作区时，台账记为「界面创建」。工具发起的同名操作不带这个来源，仍记为「工具创建」。台账保留第一次写入的来源。子会话挂在父会话下面。页头「终端 N」与快照里的窗格一致；DSH 在空会话不挂载页头操作槽，见下方限制。

### 中文

界面文案跟随 DSH 语言。中文下工作室眉题是「工作区工作室」，页眉是「Herdr / 工作区工作室」，侧栏和 DSH 面板标签是「工作台」，没有 Agent 名时的类型名是「终端」。待处理说明使用「等待介入」和「回合结束」，不再夹英文状态词。Herdr、DSH 保持原样。`tests/unit/copy.test.ts` 检查中英对照，并拦住新的硬编码英文。

### 状态

Herdr 0.9.3 的 `AgentStatus` 是 `idle | working | blocked | done | unknown`。别名会折到这五项。普通 Shell 的 `unknown` 在右侧栏显示为「空闲」加「终端」；有 Agent 名但没有生命周期时显示「未上报」。待办不会把未分类状态当成已完成。

## 真机验证

维护者在真实 **DSH 0.2.1-rc.2 + Herdr 0.9.3** 上安装过本分支的候选包，并确认了这些结果：

- 右侧栏空态可用：有样式、图标和创建按钮。
- 绑定后的树曾出现层级弱、状态不友好、标签页显示成 `1`、待处理说明和页眉仍是英文。这些问题已在后续提交里改完。
- 中文补全已由维护者确认。

仓库 CI 在每次推送上运行真实 Herdr 0.9.3，并把最终 tarball 装进 DSH 0.2.1-rc.2，覆盖认证、终端、网关和卸载。`docs/screenshots/` 来自 dev-workbench，不是那次真机画面。发行包以合并后 main 的 `build.json` SHA 为准，不要把 PR 分支上的截图或旧候选包 SHA 当成已发布构件。

## 已知限制

- 空会话（Into the Unknown）不挂载 `conversation.session.header.actions`，「终端 N」要等会话离开 blank。在那之前用右侧栏。
- 「打开工作台页」在真实 DSH 里调用 `layout.selectPanel('workbench')`，打开全局主面板，初始页是总览。
- 右侧栏页签芯片若在手势中被宿主重绘，第一次点击仍可能被 Chromium 取消。插件不改宿主 DOM。
- 给模型的工具说明仍是英文。批准框的用户可见文案是中英对照。
- 物理中文输入法、读屏器、触屏、长时间性能、macOS、原生 Windows 和其他 DSH/Herdr 版本未宣称通过。原生 Windows 请在同一个 WSL Linux 里同时运行 DSH 与 Herdr。
- 这不是稳定版，也不是 npm 发布。GitHub 仓库仍在原 fork 网络里。

## 安装

核对环境：**Linux x86_64、Node 24.22.0、pnpm 10.28.2、DSH 0.2.1-rc.2、Herdr 0.9.3 / protocol 22**。DSH 与 Herdr 必须在同一台 Linux 或同一个 WSL。把这一版的 `.tgz`、`SHA256SUMS`、`build.json`、`sbom.cdx.json` 放在同一目录后检查校验值：

```sh
sha256sum --check SHA256SUMS
dsh plugin --profile web remove @namewta/dsh-workbench
dsh plugin --profile web add /absolute/path/namewta-dsh-workbench-1.0.3-alpha.1.tgz
```

然后重启正在运行的 DSH Web，并重新加载已打开的标签页，让宿主和浏览器使用同一版本。首次安装可以省略 remove。替换插件不会删除外部工作区，也不会停止 Agent。面板默认只读。

`build.json` 标明这次 main 验收的源码 SHA。`SHA256SUMS` 是完整性记录，不是代码签名。三项 main 检查都通过后，CI 才发布这一版；tag 已存在时不会覆盖。
