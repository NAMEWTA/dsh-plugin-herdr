# Workbench 1.0.2-alpha.1

**Terminal startup hotfix / 终端连接修复预发布版。** GitHub prerelease only; no npm publication or overwrite of older releases.

## Fixes

- Eliminate the separate website-root terminal asset request. The renderer travels with the public DSH plugin client and initializes only when a pane is opened. This fixes the reproduced failure in which the main UI works but a missing terminal asset causes a generic internal error before lease acquisition.
- Add stable browser-side renderer/load diagnostics, real request-ID preservation, safe read-only retry, single-flight initialization and correct out-of-order loader disposal.
- Dispose partially initialized xterm resources and release their lease when initialization fails. Control/adoption/takeover still require explicit permission; input is never replayed.
- Add before/after tests using the actual previous-release tarball and the new tested package; retain the real DSH/Herdr terminal and gateway acceptance gates.

The original screenshot contains no deployment trace. The documented asset-load failure is reproduced, but this is not a claim to have examined the user's private proxy or logs. See `docs/terminal-startup-fix.md` for the evidence boundary and initial-transfer-size tradeoff.

## Upgrade

Verified target: Linux x86_64, Node 24.22.0, DSH 0.2.1-alpha.2 and Herdr 0.9.3 / protocol 22. Download all four assets into one directory and verify them:

```sh
sha256sum --check SHA256SUMS
# Back up profile configuration; replace in the same Web profile.
dsh plugin --profile web remove @namewta/dsh-workbench
dsh plugin --profile web add /absolute/path/namewta-dsh-workbench-1.0.2-alpha.1.tgz
```

Restart the running DSH Web process, then fully reload every open DSH tab so host and browser use the same version. On a fresh installation omit removal. No external workspace or Agent is deleted/stopped by replacement. Default pane entry is read-only.

`build.json` identifies the exact accepted main commit; `SHA256SUMS` covers package and metadata; CycloneDX SBOM and license notices remain included. Checksums are integrity records, not code signatures. Publication remains gated on all three main acceptance jobs. Physical IME/touch/screen-reader, other platforms, performance and fork-detachment limits remain open; this is not a stable release certification.
