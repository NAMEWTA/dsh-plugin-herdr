# Workbench 1.0.1-alpha.1

**Patch prerelease / 补丁预览版。** Numeric patch increment from 1.0.0-alpha.1; the alpha designation is intentionally retained. No npm publication and no overwrite of earlier releases.

## Changes / 变更

- Includes the session-aware Herdr Workspace Studio from PR25: module icon rail, secondary workspace/tab/pane navigation, separate administration, current-conversation workspace binding, and direct readonly pane viewing with explicit control/takeover.
- Reconciles the remaining branch/PR changes into the current architecture. Filesystem-root and prefix/symlink boundary regressions from #18 are preserved. #20's old RPC fix is superseded by the validated single-request Remote contract, without restoring incompatible legacy interfaces.
- Ports #22's pane inspector: real pane/workspace/tab IDs, truthful foreground directory, verified executable/full socket, and six copy-only readonly CLI commands. Shell values are quoted; unknown endpoints, disappeared/replaced targets and failed clipboard operations fail visibly. No command execution or implicit control.
- Preserves original branch commits in merge ancestry before deleting redundant branch pointers. Detailed conflict resolutions are in `docs/consolidation-1.0.1.md`.

## Install

Verified target remains **Linux x86_64, Node 24.22.0, pnpm 10.28.2, DSH 0.2.1-alpha.2, Herdr 0.9.3 / protocol 22**. Download the tarball, `SHA256SUMS`, `build.json`, and `sbom.cdx.json` into one directory and run `sha256sum --check SHA256SUMS`.

```sh
# Replace the installed Workbench in the same Web profile, then restart DSH Web.
dsh plugin --profile web remove @namewta/dsh-workbench
dsh plugin --profile web add /absolute/path/namewta-dsh-workbench-1.0.1-alpha.1.tgz
```

For a first installation, omit removal. If still using `@namewta/dsh-plugin-herdr`, remove that old package instead. Back up profile configuration before replacing the plugin. Installation/uninstallation does not delete external workspaces or stop their agents. Old aliases and configurations are not revived by branch consolidation.

## Verification and limits

Publication requires the merged main commit to pass the complete acceptance pipeline, including exact-tarball installation into published DSH, real terminal input, explicit two-client takeover, authenticated gateway security and uninstall. The inspector additionally has real-daemon readonly CLI checks, clipboard-error coverage and responsive accessibility tests. Build metadata identifies the source SHA; checksums are integrity records, not a code-signing claim.

This is not stable certification. Physical IME/touch/screen-reader acceptance, long-duration performance, other platforms, GitHub fork detachment and final branding remain documented work. Multihost, structured chat, PWA and a production standalone host are not included. Use the real-shell console only on trusted devices in a private authenticated environment. CLI snippets are copy-only and reflect the inspected target at the time of copying, not a lasting lease.
