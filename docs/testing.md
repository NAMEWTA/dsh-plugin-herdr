# 验证分层与证据

## 自动化入口

`pnpm quality` 顺序执行构建、严格类型、依赖方向/CSS/公开 exports 门禁、Herdr fixture 与 Remote 生成漂移检查、Node 单元回归、React 组件和最终 tarball 检查。浏览器和真实 Herdr 是额外必需任务，不混进“质量检查通过”这一短语。

`tests/integration` 使用私有 HOME/XDG/socket 和固定 Herdr 0.9.3：真实创建/重命名/分拆/外部接管、绑定、观察全帧、输入 ACK、resize、双窗口控制冲突、接管和关闭桥接。缺二进制直接失败。

`tests/e2e/run.mjs` 通过 HTTP 访问真实开发 UI：375/768/1280/1920 × 明暗 × 两种密度，另有加载/空态/过期/离线/不支持/无权限/大表格，键盘和焦点、第二模块，共 25 项。保存截图与 axe 报告。`--offline` 仅用于受管浏览器不能导航网络时的独立组件渲染，结果 JSON 明示其不能证明 HTTP/gateway 正常。

`tests/e2e/dsh.mjs` 安装本次候选 tarball 到全新 DSH profile，不用开发源码替换最终包。验证公开槽位与 Remote、环境、真实工作区创建、终端懒加载、双向输入/ACK、两窗口控制/接管、Origin/匿名拒绝和卸载。使用公开首启流程，不注入 API key 或请求 LLM，不留下测试工作区。

## 旧测试的处理

旧基线的整体 `pnpm quality` 已在 Node 24 重跑，而不是根据历史 PR 文字判断失败。旧 API、宿主 DOM/Fiber、旧预设、旧品牌和三版本兼容矩阵已经删除，其源码字符串断言不再是新产品契约。

仍然成立的终端 manager、协议、NDJSON、全帧/差量、配额与清理语义迁入模块并保留回归。新测试补充平台生命周期、存储命名空间与 CAS、客户端身份、authority/epoch、输入 ACK/backpressure、模块第二实例和组件行为。不能用“新测试更少”宣称覆盖率更高；真实边界仍需独立集成。

## 已发现并修复的验证问题

- XDG 环境未随桥接传递，真实 Herdr 找不到对应终端；保留必要路径变量，仍不继承 API 密钥。
- 首次附着误用短断线宽限，慢资源检查/冷渲染器造成租约提前回收；独立初次附着期限并先加载渲染器。
- 原终端库进入首屏脚本；改为独立同源按需资源。
- Tailwind 生成全局选择器；对最终 CSS AST 统一限定作用域并自动检查。
- 表单 label 包住所有 option，导致可访问名称错误；独立关联 label/id/description。
- 输入队列直到整批 ACK 才释放额度；逐条 ACK 释放，并测试重复/缺失 ACK 不重放。

## 必须区分的证据

本地日志、GitHub CI 运行、模拟截图、真实 DSH 截图和人工验证是不同证据。CI artifact 含当前 build SHA、版本、候选包哈希、SBOM、浏览器报告及脱敏日志。不要把旧提交的成功结果复制为新提交已经通过。

人工 CJK IME、物理软键盘、真实读屏器以及设计中的固定设备长时性能预算仍需要独立记录，详见验收清单。
